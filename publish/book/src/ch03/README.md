# NATS: The Communication Backbone

NATS is the messaging system at the heart of Gorai. This chapter covers how Gorai uses NATS for robot communication.

## Why NATS?

NATS provides:

- **Simplicity**: Single binary, zero configuration
- **Performance**: Millions of messages per second
- **Reliability**: At-least-once delivery with JetStream
- **Flexibility**: Pub/sub, request/reply, and streaming
